DATA & METHODOLOGY

A view of the archive.

This explorer uses NASA SPDF’s SSCWeb definitive ephemerides, spacecraft IDs rbspa and rbspb. SSCWeb identifies their source as mission SPICE files supplied by Johns Hopkins APL. Predictive spacecraft IDs are never requested.

What a point means

Each marker is an archived Cartesian position at the sample UTC shown in its card. SSCWeb’s native cadence is 60 seconds. Exact samples are the default. The optional nearest-sample setting shows a real sample within 30 seconds and identifies its time offset; it does not calculate a position at the requested time. No marker is shown outside coverage or across a gap.

Coordinates and scale

SSCWeb performs the requested GEO, GSE or GSM conversion. The client divides returned kilometers by 6,378.16, the Earth-radius convention in the SSCWeb user guide, and computes radial distance as √(X² + Y² + Z²). The 3D coordinates use the same right-handed axes. Earth is a spherical scale reference; its grid is schematic, not a geographic map. Marker sizes are exaggerated.

L, magnetic local time and magnetic latitude

Each probe card includes NASA SSCWeb’s centered-dipole L, Solar Magnetic (SM) MLT in decimal hours, and spacecraft MLAT in degrees. L is a dimensionless normalized equatorial crossing radius in the centered-dipole model; it is distinct from McIlwain L and drift-shell L*. MLAT is latitude at the spacecraft, not invariant or footprint latitude. SM latitude is measured from the magnetic equator; MLT is 12 at magnetic noon and 0 at midnight.

These values are returned by a separate NASA SSCWeb query using the same definitive spacecraft IDs and native timestamps. The app matches them exactly to the plotted position sample, including its timestamp when nearest-sample display is enabled. It does not interpolate, run a magnetic model locally, or substitute radial distance for L. A missing value or request failure remains unavailable. The magnetic coordinates stay in SM when the Cartesian display frame changes.

Paths, gaps and mission boundaries

Paths are straight segments between consecutive 60-second records in the selected coordinate system. They provide sampled trajectory context, not a propagated orbit. No segment crosses a missing record. GSE and GSM axes change orientation with time, so the trail is a history in the selected frame. Fainter lines indicate future samples relative to the selected timestamp.

Operations ended for Probe B on 19 July 2019 and Probe A on 18 October 2019. Archive coverage ends earlier within those dates; an operating spacecraft may still have no ephemeris record. The controls allow the full mission date range and report each probe separately.

Retrieval and offline use

Initial data are genuine bundled SSCWeb responses for 16–19 March 2015 in all three coordinate systems. Other dates load on demand from SSCWeb over HTTPS, in bounded chunks. Imported datasets can extend offline coverage. A failed request is reported as a retrieval failure, not as proof of a physical data gap. The included Python downloader saves source responses and their provenance. See README.md for commands.

Measured geomagnetic indices

NASA OMNI provides ground-derived AE and SYM-H indices from WDC Kyoto at 1-minute resolution. Both use the selected minute, with the source timestamp at its start: 12:59:00 represents [12:59:00, 13:00:00) UTC. The original source timestamp and interval are shown. Missing records and fill values stay unavailable; neither index is interpolated. SYM-H replaces the hourly Dst display. It measures the symmetric horizontal disturbance using a different station set and a slightly different coordinate system from Dst. These global indices are independent of spacecraft availability. NASA classifies mission-era AE and SYM-H as provisional at period level; no per-record quality flag is supplied. NASA source and status · Kyoto SYM-H definition.
